# HackBuzz 🚀  
### Unified Student Portal for Inter-College Hackathons & Events

HackBuzz is a centralized platform designed to help students discover inter-college hackathons, workshops, coding contests, and collaborative opportunities. It solves the problem of scattered event information across social media platforms by providing a single, secure, and structured ecosystem for student collaboration.

---

## 📌 Problem Statement

Students often miss hackathons and collaborative opportunities because event information is scattered across platforms like WhatsApp, Telegram, and Instagram. Additionally, finding teammates from different colleges with matching skills is difficult and unstructured.

HackBuzz addresses these issues by offering:
- Centralized event discovery
- Verified student access
- Skill-based team formation
- Project collaboration tools

---

## 🎯 Objectives

- Centralize inter-college event listings
- Enable secure student authentication using college email otp based registration
- Provide skill-based team formation
- Support project posting and collaboration
- Offer dashboards for event and team management
- Build a scalable and secure backend architecture

---

## ✨ Features

### ✅ Current Features
- 🔍 Centralized listing for hackathons, workshops, debates, and competitions  
- 📧 Only college students can register by otp verification through college email 
- 👥 Team creation and joining based on skills  
- 📊 User dashboard for events, teams, and profile management  
- 💡 Project posting and collaborator matchmaking  
- ☁️ Cloud-hosted MongoDB database  

### 🚀 Future Enhancements
- 🤖 AI-based personalized event recommendations  
- 🧠 Advanced team-matching algorithm  
- 💬 Real-time chat for teams and events  
- 🔔 Push notifications for deadlines and updates
